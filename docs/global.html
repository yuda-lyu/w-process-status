(async) autoDownloadFiles() → {Promise}

Description:

  • 取得processStatus.exe，回傳processStatus.exe的絕對路徑

    經ensureBins依bin/manifest.json之SHA-256與大小校驗後取得(快取、鏡像、GitHub釘選提交)，首次使用才下載，安裝時不下載， 離線與內網之用法(W_BIN_CACHE、W_BIN_MIRROR、W_BIN_OFFLINE)見README〈外部執行檔〉

    供w-process-status自身與其他依賴w-process-status的套件調用，無須各自實作偵測與下載邏輯

    因processStatus.exe只能用於Windows作業系統，故調用前須自行檢核作業系統

Source:
  • autoDownloadFiles.mjs, line 36
Example
import autoDownloadFiles from 'w-process-status/src/autoDownloadFiles.mjs'

async function test() {

    //autoDownloadFiles, 無快取時自動取得, 取得或校驗失敗則reject
    let { fpExe } = await autoDownloadFiles()

    console.log('fpExe', fpExe)
    // fpExe D:\xxx\node_modules\w-process-status\bin-cache\<sha256>\processStatus.exe
}
test()
    .catch((err) => {
        console.log('catch', err)
    })
Returns:

回傳Promise，resolve回傳執行檔路徑物件，內含fpExe為processStatus.exe的絕對路徑字串，reject回傳帶code之Error(E_OFFLINE_MISSING、E_HASH_MISMATCH等)

Type
Promise

ensureBins(optopt) → {Promise}

Description:

  • 取得本套件之外部執行檔processStatus.exe: 首次使用時下載(或自鏡像取得)並以bin/manifest.json之SHA-256與大小校驗, 之後自快取取得(亦校驗) 規格: 外部執行檔之存放下載校驗與離線(制式規格)§6; 實作為wsemi之fsEnsureBins, 本套件不另寫下載、快取、鏡像、校驗 環境變數: W_BIN_CACHE、W_BIN_MIRROR、W_BIN_OFFLINE, 見README〈外部執行檔〉

Source:
  • ensureBins.mjs, line 34
Example
import ensureBins from 'w-process-status/src/ensureBins.mjs'

async function test() {
